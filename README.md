# NEXORA AI — AI Product Landing Page

A modern, responsive landing page for **NEXORA AI**, a fictional AI productivity platform designed to help users research, write, organize ideas, study, and automate repetitive tasks.

## Overview

NEXORA AI demonstrates how a polished AI startup website can be created using fundamental web technologies and AI-assisted development. The project focuses on clean UI design, responsive layouts, accessibility, and modern CSS techniques.

## Features

* Modern AI/SaaS-inspired design
* Fully responsive layout
* Hero section with AI interface mockup
* Feature showcase
* Product workspace preview
* Three-step workflow section
* Statistics and testimonials
* Responsive pricing section
* Interactive FAQ using HTML `<details>` elements
* Final call-to-action section
* Professional footer
* CSS animations and hover effects
* Accessible semantic HTML
* Reduced-motion support
* No JavaScript required

## Technologies Used

* **HTML5** — Structure and semantic content
* **CSS3** — Styling, animations, responsive design, gradients, and layouts
* **Claude AI** — AI-assisted development
* **GitHub Pages** — Static website hosting
